# 让每一次修改，都只留下真实的差异。

Y Note 是一个本地优先的 Markdown 编辑器。它将优雅的所见即所得体验，
与字节级可靠的 Git 友好保存结合在一起。

## 01 原始源码是唯一事实

编辑器不应该在保存时“重新理解”整篇文档。
**Tiptap 负责编辑体验，SourceBuffer 负责文件真相。**

> 保存是源区间补丁，不是全文导出。
> __强调__、CRLF、BOM 和末尾空白均保持原样。

当用户修改一个段落，我们只更新这个段落对应的 `SourceSpan`。
其他块没有进入保存管线，因此也不会产生意外的 Git 差异。

- [x] 原始编码、BOM 与换行风格保持
- [x] 未编辑块永不重新序列化
- [ ] 复杂结构使用局部源码安全降级
